- Responsive portfolio design
- Home/hero section
- About Me section
- Education section
- Skills section
- Services section
- Projects showcase
- Contact Me page
- Hire Me page

- Social media links

- Profile and project images

- HTML5
- CSS3
- JavaScript
- Font Awesome
